# frontend

Frontend application — Vite + React + TypeScript.

## Setup

```bash
cd frontend
pnpm install
pnpm dev
```

## Structure

```
frontend/
├── src/
│   ├── puzzle/       # State puzzle UI
│   ├── pages/        # State pages
│   ├── risk/         # Risk layer
│   ├── store/        # Zustand store
│   ├── components/   # Shared UI
│   └── lib/          # Utilities
├── public/
└── index.html
```
