# ONBOARDING.md — ValenceYou

## For New Contributors

Welcome. This project serves Chinese trans communities. Read **REMEMBER.md** before writing any code.

---

## Prerequisites

- Node.js 18+
- pnpm
- Git

## Setup

```bash
git clone https://github.com/Mizauka/ValenceYou.git
cd ValenceYou
pnpm install
pnpm dev
```
